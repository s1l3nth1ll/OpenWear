# OpenWear Code of Conduct
 
## Our Commitment
 
OpenWear is intended to be an open and welcoming project.
 
We want contributors of different experience levels and backgrounds to be able to participate safely and constructively.
 
---
 
## Expected Behavior
 
Contributors are expected to:
 
- Be respectful
- Be constructive
- Assume good intentions
- Focus on technical issues rather than individuals
- Accept constructive criticism
- Respect different levels of experience
- Protect other users' privacy
 
---
 
## Unacceptable Behavior
 
The following behavior is not acceptable:
 
- Harassment
- Personal attacks
- Threats
- Discrimination
- Hate speech
- Deliberate disclosure of private information
- Sexual harassment
- Trolling intended to disrupt the project
- Malicious behavior toward contributors or users
 
---
 
## Technical Disagreements
 
Technical disagreements are expected.
 
Arguments should focus on:
 
- Evidence
- Design requirements
- Security
- Privacy
- Maintainability
- User experience
- Project goals
 
Disagreement with an idea is not disagreement with the person proposing it.
 
---
 
## Enforcement
 
Project maintainers may remove, edit, or reject contributions that violate this code of conduct.
 
Serious or repeated violations may result in temporary or permanent removal from project spaces.
 
---
 
## Reporting
 
If you experience or witness unacceptable behavior, contact the project maintainers privately.
 

    Security issues should be reported according to [`SECURITY.md`](SECURITY.md).
